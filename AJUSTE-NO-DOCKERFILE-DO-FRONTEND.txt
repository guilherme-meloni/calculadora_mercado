No SEU Dockerfile do frontend (raiz do projeto, não é o do mercado-api), no Stage 1 (builder),
adicione estas duas linhas ANTES do "RUN npm run build":

    ARG VITE_MERCADO_API_URL
    ENV VITE_MERCADO_API_URL=$VITE_MERCADO_API_URL

Fica assim (só essas duas linhas são novas):

    FROM node:20-alpine AS builder

    WORKDIR /app
    COPY package.json ./
    RUN npm install
    COPY . .
    ARG VITE_MERCADO_API_URL
    ENV VITE_MERCADO_API_URL=$VITE_MERCADO_API_URL
    RUN npm run build

    FROM nginx:alpine
    COPY --from=builder /app/dist /usr/share/nginx/html
    COPY nginx.conf /etc/nginx/conf.d/default.conf
    EXPOSE 80
    CMD ["nginx", "-g", "daemon off;"]

Por quê: o Vite grava a URL da API dentro do JavaScript já compilado (é o navegador do celular que
chama essa URL depois, não o container). Sem essa mudança, o build ignora o VITE_MERCADO_API_URL
do docker-compose.yml e o app não sabe onde está a sua API.
