# DOCUMENTAÇÃO DO PROJETO: CALCULADORA DE MERCADO (MERCADO-CALC)

Este documento descreve a arquitetura, o design UI/UX e o funcionamento técnico do projeto "Calculadora de Mercado". Ele foi estruturado para que outra Inteligência Artificial possa compreender rapidamente o sistema e como ele foi construído.

---

## 1. VISÃO GERAL
A "Calculadora de Mercado" é uma aplicação web (PWA) desenvolvida para ajudar usuários a controlar seus gastos em tempo real durante as compras. Diferente de uma lista de compras estática, ela foca no cálculo dinâmico e na organização visual por meio de cards interativos.

---

## 2. STACK TECNOLÓGICA
- **Framework:** Svelte (Reatividade nativa sem Virtual DOM).
- **Build Tool:** Vite.
- **Estilização:** Vanilla CSS (Design System customizado).
- **Persistência:** LocalStorage (Sem necessidade de banco de dados externo).
- **Infraestrutura:** Docker + Nginx (Otimizado para produção).

---

## 3. UI/UX DESIGN (SISTEMA VISUAL)

O design segue uma estética batizada de **"Gruvbox Pastel Rosa"** com **"Geometria Chubby"**.

### Identidade Visual
- **Cores Principais:**
  - Fundo (`--bg`): Creme quente (#FFF8F5).
  - Cards (`--surface`): Branco puro.
  - Destaques (`--accent`): Rosa âncora (#C2546E).
  - Sucesso/Ativo (`--accent2` / `--green`): Verde feira (#6B9E6B).
  - Bordas: Rosa pastel suave e médio.
- **Tipografia:** Fonte 'Nunito', com pesos pesados (600 e 900) para facilitar a leitura rápida em movimento.
- **Geometria:** Bordas extremamente arredondadas (`radius-lg: 24px`, `radius-xl: 32px`), conferindo um aspecto amigável ("Chubby").

### Layout e Experiência
- **Mobile-First:** Interface pensada para uso com uma mão no supermercado.
- **Cards Interativos:** Cada produto é um bloco visual independente com controles de quantidade (+/-) e checkbox de "no carrinho".
- **Feedback Instantâneo:** O valor total é atualizado em tempo real na `TotalBar` fixa na parte inferior.
- **Navegação:** 
  - Mobile: `BottomSheet` para menus e troca de listas.
  - Desktop: Sidebar lateral persistente em layout grid.
- **Safe Areas:** Suporte total a entalhes (notches) de iPhones e Androids modernos.

---

## 4. ARQUITETURA DE DADOS E ESTADO (STORE)

O "coração" da aplicação reside em `src/lib/store.js`.

### Modelo de Dados
- **State Global:** Um objeto único contendo `activeId` (ID da lista atual) e um array de `lists`.
- **Estrutura de uma Lista:**
  - `id`, `name`, `items` (Array), `isTemplate` (Boolean), `archived` (Boolean).
- **Estrutura de um Item:**
  - `id`, `nome`, `preco`, `qty`, `cat` (emoji de categoria), `checked`.

### Fluxo de Reatividade
1. O usuário interage com um componente (ex: clica em +1).
2. O componente invoca uma função da `appStore`.
3. A `appStore` atualiza o estado usando o padrão `writable` do Svelte.
4. Um `subscribe` automático serializa o novo estado no `LocalStorage`.
5. `Derived Stores` (como `items` e `activeList`) filtram e ordenam os dados automaticamente para a interface.

---

## 5. PRINCIPAIS FUNCIONALIDADES

1. **Gestão de Múltiplas Listas:** Criação, renomeação, deleção e arquivamento de listas independentes.
2. **Templates (Modelos):** Listas marcadas como templates podem ser duplicadas para iniciar novas compras rapidamente.
3. **Histórico:** Listas arquivadas ficam acessíveis para consulta ou reabertura.
4. **Importação Inteligente:** Parser capaz de transformar texto colado (ex: "Tomate; 5,50; 2") em itens da lista, com detecção inteligente de preço e quantidade.
5. **Ordenação Dinâmica:** Itens podem ser ordenados por nome ou preço (crescente/decrescente).
6. **Modais Customizados:** Sistema de diálogos (confirm, prompt, edit) integrado ao estado do Svelte para uma UX coesa.
7. **PWA & Badge:** Suporte a ícone na home e "App Badge" que mostra o número de itens restantes no ícone do app.

---

## 6. ESTRUTURA DE ARQUIVOS CHAVE

- `src/App.svelte`: Orquestrador principal e layout base.
- `src/lib/store.js`: Lógica de negócio e persistência.
- `src/lib/design-system.css`: Tokens de design e estilos globais.
- `src/components/InputCard.svelte`: Formulário de entrada de novos produtos.
- `src/components/ItemList.svelte`: Container que renderiza os produtos da lista ativa.
- `src/components/TotalBar.svelte`: Barra inferior com o resumo financeiro.
- `src/components/BottomSheet.svelte`: Menu deslizante para navegação mobile.

---

## 7. NOTAS PARA OUTRAS IAs (COMO ESTENDER)

- **Para adicionar um novo tema:** Altere as variáveis no `:root` do `design-system.css`.
- **Para adicionar uma nova regra de negócio:** Insira a lógica dentro de `createAppStore` no `store.js`.
- **Para criar novos componentes:** Siga o padrão de usar as classes `.glass` para containers e `itemsActions` para disparar ações de modificação de dados.
- **Importante:** Todos os dados são locais. Se precisar de sincronização em nuvem, será necessário implementar um backend e modificar o `subscribe` do `store.js`.
